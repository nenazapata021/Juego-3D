# Juego 3D

Un juego 3D simple creado con Vite y Three.js.

## Descripción

Un proyecto de demostración que muestra capacidades de renderizado 3D usando Three.js dentro de un entorno Vite.

## Características

- Renderizado 3D con Three.js
- Estructura modular con ES modules
- Build optimizado con Vite

## Scripts disponibles

- `npm run dev` - Inicia el servidor de desarrollo Vite
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Vista previa del build de producción

## Tecnologías

- [Vite](https://vitejs.dev/) - Build tool y dev server
- [Three.js](https://threejs.org/) - Librería 3D
